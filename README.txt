مشتری‌یار v0.9 — Vercel Ready

این نسخه برای انتشار به‌صورت Web App روی Vercel آماده است.

آپلود:
1. فایل‌های این پوشه را در یک GitHub repository قرار دهید.
2. در Vercel: New Project > Import Git Repository.
3. Repository را انتخاب کنید.
4. Framework را Other/Static بگذارید و Deploy کنید.
5. بعد از انتشار، آدرس HTTPS را در Chrome اندروید باز کنید و Add to Home screen را بزنید.

نکته مهم:
v0.9 هنوز Backend واقعی، احراز هویت ابری، دیتابیس ابری و درگاه پرداخت واقعی ندارد.
اطلاعات فعلاً در مرورگر دستگاه ذخیره می‌شود.
برای دریافت پول واقعی از کاربران، نسخه v1.0 باید Auth + Database + Subscription + Payment Gateway داشته باشد.
